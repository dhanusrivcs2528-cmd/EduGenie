# EduGenie

EduGenie is an AI-powered educational assistant built with:

- Python
- FastAPI
- Google Gemini
- HTML
- CSS
- JavaScript
- Pydantic

## Features

1. Question and Answer
2. Concept Explanation
3. Quiz Generation
4. Text Summarization
5. Personalized Learning Path
